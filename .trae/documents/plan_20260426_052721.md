## BNotes 读书笔记系统实施计划

### 1. 项目初始化
- 创建项目目录结构
- 初始化 composer.json (PHP) 和 package.json (Vue)
- 配置 Vite + Vue 3 开发环境

### 2. 后端搭建
- 创建 SQLite 数据库和表结构
- 实现 PHP API 接口（书籍、笔记、分类、标签、搜索、导出）

### 3. 前端搭建
- Vue 3 基础组件：侧边栏、头部、笔记编辑器
- 页面：书架、笔记编辑/查看、搜索结果
- 状态管理：Pinia stores

### 4. 核心功能开发
- 书籍 CRUD + 分类/标签系统
- 笔记编辑（富文本）+ 关联跳转
- 搜索筛选（分类/标签/状态）
- 阅读进度追踪
- 批量操作（删除/移动/导出）
- PDF 导出
- 暗色模式
- 快捷键支持

### 5. 桌面打包
- Electron 配置
- 打包为 .exe
