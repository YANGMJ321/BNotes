# BNotes 读书笔记管理系统

一个简洁高效的读书笔记管理工具。

## 功能特点

- 📚 书籍管理 - 每本书一份完整笔记
- 🏷️ 分类标签 - 书架分类 + 多标签支持
- 📊 阅读进度 - 百分比追踪
- 🔍 全局搜索 - 快速查找
- 🌙 暗色模式 - 护眼主题
- ⌨️ 快捷键 - 高效操作
- 📱 响应式 - PC/手机均可

## 技术栈

- **前端**: Vue 3 + Vue Router
- **桌面**: Electron 28
- **后端**: PHP 8 + SQLite（可选）
- **构建**: Vite 5
- **打包**: electron-builder 24

## 开发

```bash
# 安装依赖
npm install

# 开发模式（网页）
npm run dev

# 打包桌面应用
npm run build:electron
```
