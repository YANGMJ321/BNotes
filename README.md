# BNotes 读书笔记管理系统

一个简洁高效的读书笔记管理工具，支持桌面端（Electron）与安卓端（书记）。

## 功能特点

- 📚 书籍管理 - 每本书一份完整笔记（金句摘录、读后感、整理笔记）
- 🏷️ 分类标签 - 书架分类 + 多标签分组
- 📊 阅读进度 - 百分比追踪 + 阅读状态（想读/在读/已读）
- 🔍 全局搜索 - 快速查找书籍与笔记
- 🎨 莫兰迪主题 - 5 套预设配色 + 色环自定义 + 深色模式
- 📄 导入导出 - HTML / PDF / BNotes 格式（ZIP），桌面与移动端互通
- 🛡️ 数据备份 - 退出与每 24 小时自动备份，保留最近 10 份，可一键恢复
- ☁️ WebDAV 云同步 - 支持坚果云、Nextcloud 等，备份上云/云端恢复
- 📱 移动端"书记" - 纯前端架构，离线可用，零网络权限
- ⌨️ 快捷键 - 高效操作

## 架构

| 平台 | 技术栈 | 数据层 |
|------|--------|--------|
| 桌面端 BNotes | Electron 28 + Vue 3 + Express + sql.js | HTTP API → Node.js → `data/bnotes.db` |
| 安卓端 书记 | Capacitor + Vue 3 + sql.js | 纯前端 → IndexedDB |

桌面端与移动端复用同一套前端视图。

## 开发

```bash
# 安装依赖
npm install

# 开发模式（网页，前端 + 后端服务）
npm run dev:all

# 仅前端热更新
npm run dev

# 仅启动后端服务（端口 18765）
npm run dev:server

# 桌面端构建产物（dist/）
npm run build

# 打包便携版桌面应用（dist 后执行）
npm run dist

# 移动端构建（mobile/ 目录下）
cd mobile && npm run build && npm run cap:sync
```
