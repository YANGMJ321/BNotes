# BNotes 读书笔记

一个简洁、高效、离线优先的桌面读书笔记管理工具。为每一本书建立完整的阅读档案：金句摘录、读后感、整理笔记，一个都不少。

## 功能特点

### 📚 书籍管理
- 书架式管理，支持列表 / 封面两种视图
- 阅读状态：想读 / 在读 / 已读，百分比进度追踪
- 自定义封面、作者、分类、标签
- 书籍之间可建立关联（笔记中输入书名或关键词即可互链）

### ✍️ 笔记写作
- 每本书三个笔记板块：**金句摘录 / 读后感 / 笔记整理**
- 全面支持 **Markdown** 语法，编辑 / 预览一键切换
- 笔记流视图：按书籍、金句、读后感、整理笔记多维度浏览
- 全局搜索：快速查找书籍与笔记内容

### 📊 阅读统计
- 概览数字卡：总藏书、想读、在读、已读、笔记条数
- 阅读状态环形图，直观展示书架构成
- 阅读趋势柱状图：按年度 / 月度统计已读数量
- 零依赖自绘图表，离线可用

### 📄 导入导出
- 导出 PDF（含书籍信息与全部笔记，自动排版分页）
- 导出 HTML / 纯文本
- ZIP 压缩包完整备份导出 / 导入
- 书籍分享：将单本书连同笔记分享给他人导入

### 🛡️ 数据安全
- 自动备份：程序退出与每日定时备份，保留最近 10 份，一键恢复
- **WebDAV 云同步**：支持坚果云、Nextcloud 等，备份上云 / 云端恢复
- 数据完全本地存储，不上传任何服务器

### 🎨 主题外观
- 5 套莫兰迪预设配色 + 色环自定义主题色
- 明暗模式一键切换

### ⌨️ 高效操作
- 常用操作快捷键支持（`Ctrl+F` 全局搜索等）

## 下载使用

1. 前往 [Releases](../../releases) 页面下载最新版 `BNotes-x.x.x-portable.exe`
2. 双击即可运行，**无需安装**，绿色便携
3. 数据保存在程序同目录的 `data/` 文件夹下，方便随程序一起拷贝迁移

## 开发

```bash
# 安装依赖
npm install

# 开发模式（前端热更新 + 后端服务）
npm run dev:all

# 构建前端产物（dist/）
npm run build

# 打包 Windows 便携版 exe（输出到 release/）
npm run dist
```

技术栈：Electron + Vue 3 + Express + sql.js
